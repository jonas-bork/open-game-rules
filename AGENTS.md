# AGENTS.md

Rust workspace (edition 2024) + Nix/direnv monorepo for a local-only game-rules app: stateless crux-core in `core/`, data in `data/games/`, shells at `shells/web` (Leptos 0.8 CSR via Trunk/wasm) and `shells/tauri`.

## Environment
- Everything goes through Nix devshells (`use flake` in each `.envrc`; direnv auto-activates). Shells are layered: `core` < `web` (+trunk/tailwind) < `desktop` (+cargo-tauri) < `android` (full SDK, the heavyweight default for tauri dir). Use `nix develop .#<shell>` manually if not using direnv.
- Never use system cargo/rustup: toolchain is pinned to 1.97.1 in `rust-toolchain.toml`, consumed by Nix (`fromRustupToolchainFile`).
- `shells/tauri/.platform-choice` (create with `desktop` or `android`) selects which flake shell the tauri `.envrc` enters; defaults to android without it.

## Verify changes (CI parity)
- Run exactly what CI runs: `nix run .#ci`. It's self-contained: runs `cargo fetch`, then all pre-commit hooks, then bare `cargo test` — no manual steps to replicate.

## Generated files (do not edit)
- `.pre-commit-config.yaml`: generated by git-hooks.nix from hook config in `nix/shared/default.nix`. Change hooks there, then re-run hooks/direnv to regenerate. It and `/target` are gitignored.
- Game database: `core/build.rs` compiles `data/games/` into `$OUT_DIR/generated-games-database.json`, consumed via `include_str!` in `core/src/game_rules.rs`. Never edit/check in generated output; adding a game triggers rebuild automatically (`rerun-if-changed`).

## Adding data (games)
- One dir per game under `data/games/<id>/` containing exactly `metadata.yml` + `rules.md`; the **dir name is the game id** referenced by UI routing. Missing file = build-time panic (not a warning).
- `metadata.yml` values: `players` and `playing-time` are plain strings parsed as exact number or `"min - max"` range (see `data-builder/src/read.rs`); `complexity` is integer 1–5; `equipment` is kebab-case list (`cards`, `dice`).
- These files also pass pre-commit yamllint/markdownlint.

## Run the shells
- Web: from `shells/web/`: `trunk serve --open` (dev, port 1420), `trunk build` (release). GitHub Pages deployment additionally passes `--public-url` and copies `index.html` to `404.html` (SPA routing).
- Desktop: from `shells/tauri/`: `cargo tauri dev`. Android: `cargo tauri android dev` — requires TCP 1420 reachable from the phone (Tauri serves the web app from your machine in dev for hot reload); APK via `cargo tauri android build --apk [--debug] [--target <arch>]`.
- Tauri builds reuse the web shell's output (`frontendDist: ../web/dist`, trunk as beforeDev/BuildCommand).
